# woody-woodpacker

## Build

```bash
make all
```

Generates the `woody_woodpacker` executable at the root of the project.

Other available rules:

```bash
make clean     # removes object files
make fclean    # removes object files + the executable
make re        # fclean + make
```

## Usage

```bash
./woody_woodpacker [elf64 binary file]
```
